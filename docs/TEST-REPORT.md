既有七頁完成載入與錯誤檢查，並測試商品編輯和購買狀態；未對所有原有功能進行完整端對端驗收，例如每一種圖片上傳、所有匯入格式、旅行 CRUD、每種錢包資料與瀏覽器上一頁情境。原始實作保留不代表所有功能已全面測過。

目前 GPS 僅前景；頁面關閉或手機鎖屏不保證運作。系統通知取決於瀏覽器支援與權限，手機可能僅顯示頁內提醒。沒有實作 PWA Service Worker 背景定位，也沒有原生 App。背景提醒規劃請見 BACKGROUND-LOCATION-PLAN.md。提醒記錄以目前瀏覽器儲存為準，清除網站資料後會重置，不提供跨裝置去重。

## 如何預覽與實測

1. 下載本分支 index.html，直接開啟可檢視與操作介面；真實 GPS 請使用 HTTPS 或 localhost。
2. 電腦可在分支資料夾執行 `python -m http.server 8000`，開啟 http://localhost:8000。手機直接連電腦的 HTTP 區網 IP 通常不能使用 GPS；需後續另行核准 HTTPS 測試站，或使用本機安全環境。本次未部署。
3. 直接體驗 Beta → 購物清單 → 提醒設定與店家，新增目前位置或地圖上的分店座標。
4. 編輯兩項未購買商品並選同一提醒店家，再按啟用定位提醒。靠近時應顯示一則包含兩項商品的提醒；標記已購後該商品應消失。
5. 重新整理後再次啟用不應立即重複通知；離開設定距離再多 100 公尺、間隔滿 30 分鐘後重入可再提醒。

## 重跑自動測試

Node.js 環境執行：

```sh
npm install
npx playwright install --with-deps chromium webkit
npm test
```

需要使用已安裝的 Chromium 時，可指定 CHROMIUM_EXECUTABLE_PATH。僅在 WebKit 無法安裝時設定 SKIP_WEBKIT=1，結果會明確記為 NOT RUN。results.json 為本次執行結果；gps-reminders.cjs 為可重跑測試。未新增自動部署工作流程。
